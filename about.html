Our Company

Travel Recommendation Co. is a travel-tech startup founded in 2025. Our mission is to help travelers discover destinations that match their interests and budget. We use simple, transparent recommendations — no ads, no sponsorships.

  • Founded: 2025
  • Headquarters: Remote-first (global team)
  • Mission: Make travel discovery personal, easy, and honest.
  • Contact: team@travelrecommendation.example

Guidance for Team Members

  1. Code style: Use 2-space indentation in HTML/CSS/JS. Keep functions small and named clearly.
  2. Branching: Never push directly to main. Create a feature branch: git checkout -b feature/your-task.
  3. Commits: Write meaningful messages like add budget filter, not update.
  4. Pull requests: Open a PR for every change, request one reviewer, and wait for approval before merging.
  5. Testing: Before pushing, test locally at http://localhost using Live Server.
  6. Data changes: New destinations go in data.js only — never hard-code in script.js.
  7. Accessibility: Every image needs an alt attribute. Use semantic tags (header, main, section).
  8. Communication: Post daily updates in the team channel. Raise blockers immediately.
