# Travel Recommendation App

A simple responsive web app that recommends travel destinations based on category, budget, and keyword search.

## Features
- Filter by category (beach, temple, mountain, city, historical)
- Filter by maximum budget
- Search bar matching name, category, or country
- Search "beach" → shows beaches
- Search "temple" → shows temples
- Search "country" → shows destinations from many countries
- Responsive card grid
- About Us page with company info + team guidance
- Contact Us page with contact info + email form

## Tech Stack
- HTML
- CSS
- Vanilla JavaScript
